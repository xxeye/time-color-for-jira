讓 Jira Timeline 一眼看懂

依團隊設定替 Planning Task、Milestone、Epic 上色，在時間軸上標出週末和國定假日，滑鼠移過去就知道要花幾個工作天。

加到 Chrome 查看原始碼

支援 Jira Cloud（*.atlassian.net）的專案 Timeline。

實際操作

34 秒、無聲：開啟插件後，在示範專案上把滑鼠移到條塊和 Milestone 上（英文介面）。

適合這樣的團隊

同時進行好幾個短週期專案，每個專案都要美術、程式、QA、行銷等不同職種接力完成。

一個 Epic 就是一個專案

例如一款小遊戲或一檔活動，幾週到幾個月就完成。

多個專案同時進行

好幾個專案排在同一條 Timeline 上，彼此的時程一眼就看得出來。

各職種依排程接力

每個職種照著排程接棒，用 Milestone 管理每個交付點。

例如：小遊戲工作室、遊戲營運活動、行銷活動、影音內容製作。

推薦用法：一條 Timeline 排程，各職種看自己那一段

這個插件是為「排程」和「執行」分開管理的團隊設計的。主看板負責排時程，各職種在自己的看板只看到自己那段排程，再開出實際要做的任務。

議題類型怎麼分

類型用途
Epic一個短週期專案，例如一款小遊戲或一檔活動
Planning Task某個職種在某段時間要做的工作，填起訖日期和「職種」
Milestone重要交付日，關聯這天前要完成的任務
Task、Story、Bug…實際動手做的工作

看板怎麼開

  1. 主看板的 Timeline 只放 Epic、Planning Task 和 Milestone，當作整個專案的排程表。
  2. 各職種看板用篩選條件只顯示自己的 Planning Task，例如 issuetype = "Planning Task" AND "職種" = "美術"（依團隊需要，也可以一併篩入 Epic）。
  3. 照著 Planning Task 的時間開出執行任務，並關聯（relates to）到對應的 Milestone。

插件在這個流程裡幫你

  • 用顏色分出排程和交付點，Milestone 顯示成菱形
  • 滑鼠移到 Planning Task 上，看到負責的職種
  • 排程時直接顯示扣掉週末和國定假日後的工作天數
  • Milestone 旁邊顯示完成度，移上去列出還剩哪些任務
  • Jira 管理員把設定寫進專案，同事裝好就能用，不用各自匯入設定檔

沒有照這個架構也能用：只要在設定檔指定你用來排程和標示交付點的議題類型，以及起始日期欄位，顏色、假日、工作天數等功能都照樣運作。議題類型也不一定要叫 Planning Task 或 Milestone。

移到 Milestone 上，關聯任務一次看完

會列出每個關聯任務的狀態、起訖日期和標題，已完成的會劃掉。不用一個個點開，就知道還剩哪些工作。

功能

議題類型配色

Planning Task、Milestone 各用自己的顏色，Milestone 可以顯示成菱形，任務一多也好找。

週末與假日

管理員列出國定假日、公司休假日和補班日，休息日直接標在時間軸上。不連到任何外部網站。

工作天數

滑鼠移到條塊上或拖曳時，顯示扣掉週末和假日後的工作天數。

Milestone 進度

移到 Milestone 上，就能看到關聯任務、完成度和 Due date。

專案設定

設定可以寫在 Jira 專案裡，同事打開 Timeline 就自動套用；也可以匯入設定檔。

配合深淺色

自動跟著 Jira 的淺色或深色主題調整。

完整功能

時間軸顯示

  • Planning Task、Milestone 自訂顏色，也可以保留 Jira 原本的顏色
  • Milestone 顯示成菱形，旁邊標出完成度與 Due date
  • 依 Jira 專案設定的旗標，Epic 顯示虛線框
  • Target end 到 Due date 的區段加深
  • 相依性線條調細、調淡
  • 隱藏目前時段的高亮（今天的藍線保留）
  • 隱藏左欄的議題編號
  • 可選擇鎖定 Planning Task、Epic 的拖曳與拉長，避免誤改日期

日期

  • 標出週末
  • 標出管理員列出的休假日；補班日照常算工作天
  • 滑鼠移到條塊上或拖曳時，顯示扣掉週末和假日的工作天數
  • 可設定每週的休息日

滑鼠移上去

  • Planning Task：顯示負責的職種
  • Milestone：列出關聯任務的狀態、起訖日期和標題
  • 已完成的任務劃線，進行中的排在最前面

操作

  • Milestone 只能整段移動，不會被拉長
  • 方向鍵左右捲動時間軸（按住 Shift 捲得更快）
  • 浮動工具列：暫停或啟用、重新讀取，位置可以拖曳調整

設定管理

  • 匯入設定檔前先預覽，和現有設定重複時會先確認
  • 匯出設定、還原上一份設定、移除站台
  • 顏色和開關跟著 Chrome 同步到你的其他電腦
  • 設定檔可以附上 Timeline 網址，一鍵開啟
  • 內建管理員設定檔產生器，不用手寫 JSON

安全與隱私

  • 使用目前的 Jira 登入，不需要密碼或 API Token
  • 任務資料只在你的瀏覽器裡使用，不會傳給開發者
  • 在專案 Timeline 先讀取專案與專案設定；有適用的專案設定或匯入設定時，才進一步讀取任務資料
  • 只讀取資料，不會修改 Jira

開始使用

一般使用者

  1. 安裝擴充功能。
  2. 如果 Jira 管理員已經把設定寫進專案，直接打開該專案的 Timeline 就好。
  3. 否則點瀏覽器工具列上的插件圖示，選「設定管理」。
  4. 在「匯入與管理」匯入 Jira 管理員提供的設定檔（JSON），確認預覽後儲存。

使用你目前的 Jira 登入，不需要輸入密碼或 API Token。

Jira 管理員

  1. 打開「設定管理」，切到「產生設定檔（管理員）」。
  2. 填入站台網址、議題類型 ID 和需要的欄位 ID。
  3. 下載設定檔，自己先匯入並打開 Timeline 確認。
  4. 沒問題後，把設定檔提供給使用者。

頁面上有查詢 ID 的連結，不用手寫 JSON。

支援範圍

  • Jira Cloud 的專案 Timeline（網址為 https://*.atlassian.net）
  • 目前不支援 Jira Server、Data Center 與自訂網域
  • 介面語言：英文（預設）、繁體中文，依瀏覽器語言自動切換
  • Jira 介面語言：英文、繁體中文

隱私

Jira 的任務資料只在你的瀏覽器裡使用，不會傳給開發者，也沒有追蹤或分析。詳細內容請看隱私政策。

Time color for Jira 為獨立開發的工具，與 Atlassian 無關。Jira 是 Atlassian 的商標。
