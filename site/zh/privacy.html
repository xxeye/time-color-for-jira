隱私政策

最後更新：2026 年 9 月 25 日

Time color for Jira（以下稱「本插件」）是獨立開發的 Chrome 擴充功能，與 Atlassian 無關。這份說明會告訴你本插件處理哪些資料、存放在哪裡，以及怎麼刪除。

重點整理

  • 本插件沒有開發者伺服器，不會把你的 Jira 任務資料傳給開發者，也沒有追蹤或分析。
  • Jira 任務資料只在你的瀏覽器裡讀取、計算和顯示。
  • 站台設定和顏色偏好會跟著 Chrome 同步到你的其他電腦，任務內容不會同步。
  • 本插件只和你正在使用的 Jira 站台連線，不會連到其他網站。假日清單由 Jira 管理員寫在設定檔或 Jira 專案設定裡。

1. 本插件處理的資料

1.1 Jira 任務資料

本插件只在 Jira Cloud（*.atlassian.net）的專案 Timeline 執行，在 Confluence 頁面不會執行。開啟 Timeline 時，本插件會使用瀏覽器目前的 Jira 登入，先向同一個 Jira 站台讀取該專案的 ID 和管理員寫在專案裡的設定（專案屬性 time-color-for-jira，沒有就略過）。有設定（專案設定或你匯入的設定檔）時，才會再讀取顯示需要的資料：

  • 議題類型、摘要、狀態、起始日期、Due date 和議題關聯
  • 管理員設定檔中指定的自訂欄位值
  • 站台的欄位、議題類型、關聯類型清單（用來確認設定是否可用）
  • 專案 ID 與專案設定（用來判斷套用哪一份設定）

這些資料只暫存在該分頁的記憶體中，有數量和時間上限，不會寫入插件的儲存空間，也不會透過 Chrome 同步。關閉分頁、停用插件，或在設定頁重新讀取時就會清除。你能看到哪些資料，完全取決於你的 Jira 帳號權限。本插件不會修改任何 Jira 資料。

1.2 帳號識別

為了判斷你有沒有登入、是否切換了 Jira 帳號（避免把上一個帳號的暫存資料顯示給下一個帳號），本插件會查詢 Jira 的「目前使用者」，但只在記憶體中保留帳號 ID，不會儲存、同步或傳到其他地方。

1.3 登入憑證

本插件不會讀取、要求或保存你的 Jira 密碼、API Token 或 Cookie。對 Jira 的請求由瀏覽器自動帶上你目前的登入狀態。

1.4 設定與偏好

下列設定存放在 Chrome 擴充功能的儲存空間：

  • Jira 站台網址、專案範圍
  • 議題類型、自訂欄位、關聯類型的 ID 與顯示規則
  • 假日與補班日清單（寫在設定檔裡時）
  • 顏色、顯示開關，以及浮動工具列的位置

如果你的 Chrome 有開啟同步，這些設定會透過 Google 的 Chrome 同步功能傳到登入同一個帳號的其他電腦，由 Google 依其隱私權政策處理。請注意，站台網址和欄位設定可能看得出你所屬的組織。

下列資料只存在這台電腦、不會同步：還沒儲存的匯入草稿，以及上一份管理員設定的備份。從 Jira 專案讀到的設定只在該分頁的記憶體中使用，不會儲存。

1.5 管理員設定檔產生器

設定頁的「產生設定檔（管理員）」只在該頁面處理你填的內容，不會連線 Jira、不會上傳，也不會儲存，關閉頁面就清空。下載的設定檔由你自己保管。你點了頁面上的查詢 ID 連結時，會在新分頁打開 Jira，使用該分頁的登入狀態。

2. 資料分享

本插件不會出售、出租或分享你的資料。資料只會送到下列對象，而且都是功能運作所必需：

對象內容用途
你正在使用的 Jira Cloud 站台（Atlassian）同站台的唯讀查詢讀取要顯示的任務資料
Google Chrome 同步設定與偏好（不含任務資料）依你的 Chrome 同步設定，同步到你的其他電腦

3. 保存與刪除

  • 任務資料暫存：關閉分頁就會清除；也可以在「設定管理 → 備份與其他操作 → 重新讀取已開啟的 Jira」清除。
  • 站台設定：在「設定管理」按「移除此站台」。
  • 顏色和開關：在面板按「重設個人偏好」。
  • 全部資料：到 Chrome 的擴充功能頁面移除本插件，這台電腦上的資料會一起刪除。其他電腦上已同步的設定，何時刪除取決於 Chrome 同步。

4. Chrome 線上應用程式商店使用者資料政策

The use of information received from Google APIs will adhere to the Chrome Web Store User Data Policy, including the Limited Use requirements.

本插件使用資料的方式遵守 Chrome 線上應用程式商店的使用者資料政策與「有限使用」規定：資料只用在本插件的功能上，不用於廣告，不出售，也不會在你不同意的情況下讓任何人查看。

5. 政策更新

內容有變動時會更新這個頁面，並修改上方的「最後更新」日期。重大變更會寫在插件的更新說明中。
